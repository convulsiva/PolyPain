# 📦 Модуль `parsers`

Модуль `parsers` — это централизованный компонент проекта **PolyPain**, отвечающий за работу с различными внешними источниками данных. Каждый источник оформлен как отдельная *фича* (feature) — независимый парсер, который реализует полный цикл получения и обработки данных: от построения URL до формирования типизированных DTO.

Пакет обеспечивает единообразную архитектуру парсеров, инкапсуляцию сетевой логики и удобную масштабируемость.

- Сделать каждую фичу независимой и легко тестируемой.

## 🧱 Архитектура

Каждая фича-парсер располагается в `parsers/features/<feature_name>` и имеет следующую структуру:

```
<feature_name>/
│
├── dtos.py          # типизированные структуры данных
├── exceptions.py    # специализированные исключения парсера
├── endpoints.py     # функции построения URL
├── scrapers.py      # классы, выполняющие HTTP-запросы
└── parser.py        # основной API-парсер
```

Файл `parsers/__init__.py` экспортирует доступные парсеры как:

```python
from parsers import weather_parser
from parsers import schedule_parser
```

---

## ⚙️ Принцип работы

1. Парсер использует общую инфраструктуру (`infra.client`), обеспечивающую:
   - HTTP-запросы
   - кэширование
   - управление cookies
   - конфигурацию сетевого клиента
2. Скрейперы выполняют запросы и валидируют ответы.
3. DTO (Data Transfer Objects) приводят данные к строгим структурам.
4. Основной класс `<FeaturePascal>Parser` предоставляет удобный API.

Пример вызова:

```python
from parsers import weather_parser

result = weather_parser.example("Saint Petersburg")
print(result.value)
```

## 🛠 Автоматическое создание новых парсеров

В пакете присутствует CLI-утилита `startparser.py`, упрощающая добавление новых фич.

Создать новый парсер можно командой:

```bash
python startparser.py <feature_name>
```

Например:

```bash
python startparser.py weather
```

После выполнения:

1. Создаётся каталог:

```
parsers/features/weather/
```

со следующими файлами:

```
__init__.py
dtos.py
endpoints.py
exceptions.py
scrapers.py
parser.py
```

2. В `parsers/__init__.py` автоматически:
   - добавляется блок импорта фичи
   - обновляется список `__all__`

Теперь новый парсер доступен через:

```python
from parsers import weather_parser
```

Автоматизация полностью исключает ручное редактирование инфраструктурных файлов.
